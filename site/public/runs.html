    training

    loss

    train loss is the mean over all micro-batches since the previous log row, so it mixes every source in proportion to the data mix; val is the aggregate held-out loss from each eval. ring = best checkpoint so far. vertical rules = resumes.

    gradient norm (before clipping)

    the trainer clips at 1.0 — clip_grad_norm_(model.parameters(), 1.0) — and reports the pre-clip total norm, so points above the rule were scaled down.

    learning rate

    throughput (tokens / s)

    wall = tokens / wall time between logs; active excludes duty-cycle sleep and battery pauses (at duty cycle 1.0 with no pauses the two coincide).

    memory (process RSS, GB)

    progress over wall-clock time

    step reached at each record's timestamp; vertical rules mark restarts, resumes and battery pauses.

    per-source eval

    held-out loss (nats/token) per source at each eval. "role" is the source in the role transcript format; "multiturn" is the history-bearing view; Δ is against this attempt's first eval.

    source gate

    bars are the loss change vs the step-0 baseline (left = better), scaled around the limit — bars cut by a double edge run off the scale; the number column has the exact value. the dark rule is the limit for that row. per-row verdicts are recomputed from the run's args with the trainer's _source_gate rules; the overall verdict is the trainer's own.
