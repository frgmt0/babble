booper privacy policy

booper (aka babble) is a language model that starts from random weights and learns only from what consenting people send it on Discord. Nothing of yours is stored until you explicitly opt in.

what is collected

If you opt in with !babble accept, the messages you address to the bot — @mentions, replies to it, and DMs — are stored as plain text. Replies that start with the correction marker are also filed as corrections. If you additionally run !babble all in a channel, everything you say in that channel is collected too; it never widens collection for anyone else, and !babble pings turns it back off.

what is published

Collected text is used to train the model and is published in a public HuggingFace dataset that anyone can download. In the published data you appear only as a salted hash (like u_9f2c…), never as your Discord id or username.

what is never collected

Your Discord id and username never leave the machine the bot runs on, and messages that are not addressed to the bot are never stored (unless you turned on !babble all for that channel). If you never opt in, the bot still replies to you, but nothing from the exchange is stored or trained on.

your choices

!babble accept — opt in. !babble decline — don't opt in; the bot still replies. !babble forget — at any time, opt out and delete everything of yours that was kept. !babble consent — see what is stored and your current choice.
